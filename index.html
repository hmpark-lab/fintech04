Technical Reference v1.3

1. 기본 기술 영역 (Technical Foundation)

테스트 환경 및 에뮬레이터

  • 원격 모니터링: ABB Ability™ Charger Care 플랫폼 활용
  • 시뮬레이션: OCPP 1.6J/2.0.1 표준 시뮬레이터 지원
  • 장비 미보유 테스트: MicroOCPP 등 오픈소스 도구와 높은 호환성

통신 및 데이터 흐름

  • 프로토콜: OCPP 1.6J (JSON over WebSocket)
  • 인증 보안: TLS 1.2+ 기반 보안 연결 (WSS)
  • 데이터: 실시간 MeterValues 및 트랜잭션 로깅

2. 제조사 API/SDK 및 개발자 도구 [공식 PDF 자료 보기]

제공 API 서비스

  • OCPP API: 충전 세션, 가격 정의, 인보이스 처리
  • Service API (Add-on): 케이블 연결 상세 및 장애 데이터
  • Demand Response API: 전력 부하 원격 제한 제어

관리용 웹 도구

  • Driver Care: 실시간 상태 맵 및 통계 리포트
  • Payment Mgmt: 결제 터미널 설정 및 내역 모니터링
  • Charger Care: 기판 레벨 원격 진단 및 보드 리부팅

3. 사용자 시나리오 및 APP 표기 정책

3.1 단계별 APP 상태 표기 기준

단계 OCPP 상태값 APP 노출 텍스트 (권장) 사용자 가이드 알림
대기 Available 충전 가능 "QR 코드를 스캔하여 충전을 시작하세요."
연결/인증 Preparing 연결 및 인증 중 "차량과 통신 중입니다. 잠시만 기다려주세요."
충전 중 Charging 충전 중 (n%) 실시간 출력(kW), 충전량(kWh), 경과시간 표시
충전 종료 Finishing 충전 완료 "충전이 완료되었습니다. 커넥터를 분리해 주세요."
유휴 상태 Finishing 유휴 상태 (점유 중) "미분리 시 유휴 요금이 발생할 수 있습니다." (타이머 노출)
장애 Faulted 점검 중 "현재 이용이 불가합니다. 인근 충전소를 이용해 주세요."

3.2 유휴 요금(Idle Fee) 정책

판단 기준

Status가 Finishing 또는 SuspendedEV이나 커넥터가 분리되지 않은 상태

APP UI 정책
  • 완료 후 경과 시간 실시간 카운트 다운 노출
  • 푸시 알림: 완료 직후, 유휴 요금 발생 5분 전 전송
  • 요금 산식: (분리 시점 - 완료 시점) - 유예 시간 기반 정산

3.3 커넥터 Lock/Unlock 시나리오

Lock 동작

충전 시작(StartTransaction) 시 물리적 잠금 수행

Unlock 요청 UI
  • 상세 페이지 내 [커넥터 잠금 해제 요청] 버튼 배치
  • 해제 실패 시 가이드: "차량 도어 잠금을 해제해 주세요"
  • 비상 상황 시 원격 UnlockConnector 명령 연동

4. 운영 가이드 및 제약사항

  • 통신 안정성: 지하 주차장 설치 시 LTE 수신 불량 대비 이더넷 유선 연결 필수
  • 부하 관리: ABB 전용 Demand Response API를 통한 사이트별 총 전력량 제한 설정 가능
  • UX 표준: ISO 15118(Plug & Charge) 기반의 심플하고 직관적인 인터페이스 지향
