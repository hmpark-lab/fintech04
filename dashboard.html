GA4 실시간 연동 설정

Google Analytics 4 측정 API를 연동하여 my:D 실제 서비스 로그 수치로 실시간 대시보드를 구축합니다.

1
구글 애널리틱스의 [관리] -> [데이터 스트림]으로 접속합니다.
2
측정 ID 복사 (형식: G-XXXXXXXXXX)
3
아래 입력창에 측정 ID를 주입하면 실시간 AI 분류 파이프라인이 자동 정렬됩니다.

Google Play Console API 연동

Google Play Developer API를 대시보드와 연결하여 사용자 리뷰 수집 및 답글 자동 게시 메커니즘을 구동합니다.

1
GCP Console에서 Service Account(서비스 계정)를 생성합니다.
2
Google Play Console에서 해당 계정에 '독자 리뷰 답글 쓰기' 권한을 부여합니다.
3
생성된 JSON 인증 파일 또는 서비스 이메일을 입력하세요.
