3.1

EC2 인스턴스 설정 및 접속

ssh -i "your-key.pem" ec2-user@your-ec2-public-ip
설명
  • Amazon Linux 2023의 기본 사용자 계정은 ec2-user 입니다.
  • pem 키 권한 문제가 있으면 아래 명령을 먼저 실행합니다.
chmod 400 your-key.pem
3.2

패키지 업데이트 및 Git 설치

sudo dnf update -y
sudo dnf install -y git
설명
  • Amazon Linux 2023에서는 yum보다 dnf 사용이 표준입니다.
  • GitHub 저장소를 clone 하기 위해 git 설치가 필요합니다.
3.3

Docker 설치 및 실행

sudo dnf install -y docker
sudo systemctl enable --now docker

현재 사용자에게 docker 실행 권한 부여

sudo usermod -aG docker ec2-user
주의
그룹 권한 적용을 위해 로그아웃 후 다시 접속해야 합니다. 
exit
# 다시 접속
ssh -i "your-key.pem" ec2-user@your-ec2-public-ip

설치 확인

docker --version
docker ps
3.4

Docker Compose 설치 (Plugin 방식)

기존의 docker-compose 단독 바이너리 방식은 최신 기준에서는 구식입니다.
Amazon Linux 2023에서는 docker compose 명령을 사용하는 plugin 방식으로 정리하는 것이 좋습니다. 
DOCKER_CONFIG=${DOCKER_CONFIG:-$HOME/.docker}
mkdir -p $DOCKER_CONFIG/cli-plugins

curl -SL https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64 \
  -o $DOCKER_CONFIG/cli-plugins/docker-compose

chmod +x $DOCKER_CONFIG/cli-plugins/docker-compose

설치 확인

docker compose version
3.5

Docker Buildx 설치 (선택)

먼저 설치 여부 확인

docker buildx version

없으면 설치

mkdir -p ~/.docker/cli-plugins

curl -SL https://github.com/docker/buildx/releases/latest/download/buildx-linux-amd64 \
  -o ~/.docker/cli-plugins/docker-buildx

chmod +x ~/.docker/cli-plugins/docker-buildx

설치 확인

docker buildx version

  • 기존 docker-compose 대신 docker compose를 사용합니다.
